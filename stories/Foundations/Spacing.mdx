# Spacing & radii

## Spacing scale

4 px base, ~1.2 ratio. Use the `--space-N` tokens, not raw px.

<div style={{ display: 'flex', alignItems: 'flex-end', gap: 18, padding: '24px 0' }}>
  {[4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96].map((s) => (
    <div key={s} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 8 }}>
      <div style={{ width: s, height: s, background: 'var(--fg-1)' }} />
      <div style={{ font: '600 11px/1 var(--font-sans)', color: 'var(--fg-1)' }}>{s}</div>
    </div>
  ))}
</div>
