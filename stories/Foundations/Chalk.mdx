# Chalk border

Stark's signature. A subtle SVG noise filter modulates the **alpha** along
every dark border — the line stays exactly where it was drawn, but parts of
it become transparent. Reads like a pencil pressed unevenly to paper.

## The three rules

1. **Strokes only.** Borders, dividers, framing. Never on text or fills.
2. **Solid bottom when shadowed.** Surfaces with a hard underline shadow
   (button press-line) get `.stark-chalk--solid-bottom` so the chalky openings
   don't compete with the shadow.
3. **Three intensities.** Same noise pattern, different alpha curves so the
   rhythm is consistent across the system.

## Customizing

Each chalky element accepts:

- `--stark-stroke-w` — stroke width (default `2px`)
- `--stark-stroke-c` — stroke color (default `var(--border-strong)`)
- `--stark-chalk-filter` — filter ID (default `url(#stark-chalk)`)

## Don't forget

`<ChalkDefs />` must be mounted somewhere in the React tree, or the filter
references resolve to nothing and borders fall back to plain solid lines.
