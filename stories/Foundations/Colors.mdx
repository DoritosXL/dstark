# Colors

Apple-leaning, cool, slightly desaturated so everything sits naturally on warm paper. Three families:

- **Ink** — cool gray neutrals. The only color most UI uses.
- **Paper** — warm off-whites. The canvas.
- **Brand** — Stark Blue, the one accent.
- **Semantic** — red / orange / green / purple / yellow for status and focus.
