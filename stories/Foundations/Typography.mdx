# Typography

- **Nunito** — sans, body, UI. Variable 200–1000.
- **Lora** — serif, italic ledes and display moments. Variable 400–700.
- **JetBrains Mono** — code.

## Rules

- Default weights: **800** for display / H1 / H2, **700** for H3, **500** for body. Nothing reads thin.
- Sentence case everywhere. Title Case only for proper nouns and the wordmark.
- No trailing periods on labels or buttons. Periods on full body sentences only.
- Emoji: not in core UI. Allowed in user-generated content.
